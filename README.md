### ✨ สถาปัตยกรรมและฟีเจอร์เด่น (Key Features)
* **Universal Neumorphic Design**: ออกแบบอินเทอร์เฟซด้วยมิติเงานูนต่ำแบบ Neumorphism ปุ่มกดมีสัมผัสตอบสนองชัดเจน คลีนตา และรองรับการใช้งานบนมือถืออย่างสมบูรณ์
* **Role-Based Access Control (RBAC)**: คัดกรองการมองเห็นเอกสารตามสิทธิ์รายแผนกและสายบังคับบัญชา พร้อมระบบรหัสผ่านชั้นที่สอง (Secondary PIN) สำหรับปลดล็อกเอกสารลับ
* **Dynamic Security Watermark**: ประทับตราลายน้ำดิจิทัลระบุชื่อผู้ใช้งานและเวลาจริงบนหน้าจอแบบโปร่งแสง เพื่อป้องกันการจับภาพหน้าจอและเสริมการตรวจสอบย้อนหลัง
* **Single Source of Truth (SSOT)**: กรอกข้อมูลคิวงานครั้งเดียว สามารถกดสลับหัวเอกสารได้ทันทีระหว่าง ใบเสนอราคา (Quotation), ใบสั่งงาน/ใบเบิก (Job Order) และใบเสร็จรับเงิน (Receipt) โดยตัวเลขตรงกัน 100%
