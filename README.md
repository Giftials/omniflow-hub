# omniflow-hub
omniflow ทำขึ้นเพื่อแก้ปัญหาการจัดเก็บเอกสารในแผนกงานต่างๆเพื่อป้องกันเอกสารสูญหายและหมดเวลาDownloadเก็บไว้ และ ป้องกันเวลาเซิฟเวอร์กลางบริษัทล่มและงานไปต่อไม่ได้
ขณะนี้อยู่ระหว่างกำลังพัฒนา
